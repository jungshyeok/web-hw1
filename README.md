## 어려웠던 점 3가지와 해결
- 1. TMDB 웹사이트에서 복사한 이미지 주소가 www.themoviedb.org 도메인이고 크기도 w1280이어서 규격과 달랐다. 도메인을 image.tmdb.org로 바꾸고, 카드는 w342, 상세 포스터는 w500, 배경은 w1280으로 크기를 맞췄다.
- 2. 기준일(2026-10-26) 박스오피스 1~5위가 모두 전날과 순위가 같아(rankInten "0", OLD) 변동 칸을 어떻게 표시할지 고민했다. 응답 값을 그대로 옮기는 원칙에 따라 다섯 편 모두 "-"로 적었다.
- 3. 카드에 줄거리 전문을 넣었더니 카드 높이가 제각각 길어졌다. 카드에는 첫 문장만 넣고, 전문은 상세 페이지의 <dd>에 넣었다.
